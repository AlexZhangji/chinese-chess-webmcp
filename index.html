说明与快捷键
引擎为 Pikafish (NNUE) 编译的 WebAssembly, 搜索全部在本机浏览器内运行, 没有分析后端。
但开启分析、或用入门/业余/较强档对弈时, 当前局面的 FEN 会发给 chessdb 公共云库; 连续的局面原则上足以还原整局棋。要完全不外发, 用"全力"档并关闭分析。
难度分档不以削减搜索深度实现 (那会产生机器特有的错误), 而是取多个候选后按分差采样。
候选表的"云库"列取自 chessdb 公共云库, 是它对该着法的定性 (正着 / 可走)。 它是一个云端引擎库, 不是人类棋谱库, 所以不代表真人在该局面的实战成绩。
评分单位是兵; 复盘用的"胜势点"是把评分压过一条自定 logistic 的结果, 用于同一局面内的相对比较, 没有拿象棋棋谱校准过, 不是胜率预测。

The engine is Pikafish (NNUE) compiled to WebAssembly. All search runs inside this browser; there is no analysis backend.
However, while analysis is on, and on the Novice / Club / Strong levels, the current position (FEN) is sent to the public chessdb cloud book; a run of positions is in principle enough to reconstruct a whole game. To send nothing at all, play on Full with analysis off.
The levels are not made by cutting search depth (that produces mistakes no human makes). The engine searches at full strength and then samples among the candidates by how much each one loses.
The "book" column comes from the chessdb cloud book: its verdict on that move. It is a cloud engine library, not a database of human games, so it says nothing about how people have actually scored from that position.
Scores are in pawns. The "win-chance points" used in review are the score pushed through a logistic curve of our own. They are for comparing moves within one position; they have never been calibrated against a corpus of xiangqi games, and are not a win probability.

Agent 工具 · WebMCP
这一页把自己的功能按 WebMCP (document.modelContext.registerTool) 注册给浏览器里的 agent。 注册的工具集只映射屏幕上有的东西: 提示开关拨到"关", 引擎分析那一项就不存在, 不是"请 agent 别看", 是没有那个工具可调。 下面这张表是此刻的真实注册表, 随开关和对局状态变。 This page registers its own features with the agent in your browser through WebMCP (document.modelContext.registerTool). The registered set of tools mirrors only what is on the screen: put the hint control on "Off" and analyze_position ceases to exist. It is not "please don't look" — there is no such tool to call.
